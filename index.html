03 · LINUX SECURITY

eBPF EDR

Linux security monitoring research that collects selected kernel-level telemetry with eBPF and turns it into behavioral alerts through a Go agent and React SOC interface.

Problem

Userland monitoring can miss activity that takes alternate execution paths or bypasses traditional API hooks.

Architecture

Linux kernel → eBPF/C tracepoints and kprobe → BPF ring buffer → Go agent → REST/metrics → React/TypeScript SOC UI.

Engineering

BTF/CO-RE, verifier-safe programs, stateful event correlation and behavior-focused detections for process, memory, file and network activity.

Security outcome

Provides a kernel-near observation point for controlled Linux detection research; the repository explicitly treats coverage and false positives as limitations.

eBPF · Linux · Go · C · React · TypeScript · Prometheus

04 · SECURITY TELEMETRY

Stream SIEM

Real-time security telemetry pipeline that normalizes authentication, DNS and firewall data, applies stateful event-time detection and stores enriched events and alerts.

Problem

Security telemetry needs consistent normalization, stateful detection and durable analytical storage across streaming workloads.

Architecture

Go loadgen/forwarder → Kafka → Apache Flink → ClickHouse, with Python validation and Kafka alert/dead-letter streams.

Engineering

Event-time windows, bounded out-of-orderness, stateful detectors, RocksDB state, checkpoints and explicit sink delivery semantics.

Security outcome

05 · IDENTITY & ZERO TRUST

Zero-Trust Identity-Aware Proxy

Go-based application-layer access control that evaluates identity, device posture, policy and adaptive risk before forwarding requests to protected services.

Problem

Network location alone should not establish trust; authenticated users and workloads still require contextual authorization.

Architecture

Client → Go IAP → identity/posture checks → policy + risk engine → protected app, with Vault PKI and an admin control plane.

Engineering

mTLS, SPIFFE-style identity, JWT verification, deny-by-default policy, posture checks, adaptive risk, certificate rotation and structured audit logs.

Security outcome

Demonstrates application-layer Zero Trust enforcement with explicit allow/deny decisions and a deterministic security-lab replay path.
